Inteligencia artificial (opcional)

Con clave, cada PDF lo lee Claude (la IA de Anthropic) y el botón ✨ Analizar y recomendar arma el resumen, el comparativo y la sugerencia. La clave se crea en console.anthropic.com → API Keys; cada PDF cuesta unos centavos de dólar. Se guarda solo en este navegador y nunca dentro del archivo. Sin clave, el sistema sigue funcionando gratis con la lectura automática básica, sin enviar tus PDF a ningún servidor.

Los demás datos también se guardan solo en este navegador.

Enviar por WhatsApp

WhatsApp no deja adjuntar archivos desde un enlace. Por eso: 1) descarga el PDF, 2) abre WhatsApp con el mensaje listo y 3) adjunta el PDF con el clip 📎 antes de enviar.
